# Rami Gavrilov — personal website

This repository is the source for the personal brand website at `ramigavrilov.com`.
The separate YugWeb business website remains at https://app-dqsdh7.v2.appdeploy.ai/.

GitHub Actions publishes the static site to GitHub Pages whenever `main` changes.
The `CNAME` file sets the intended personal domain; the domain's DNS must point to
GitHub Pages for visitors to see this deployment at `ramigavrilov.com`.
